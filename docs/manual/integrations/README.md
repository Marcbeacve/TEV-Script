# Integraciones

La semántica portable de TEVScript no cambia por el host. Cada integración se documenta con cinco fronteras: semántica TEVScript; responsabilidad del adaptador/proveedor; conversiones del host; concesión de capacidades; supuestos no soportados.

Integraciones cubiertas: Python, JavaScript, C#, Unity, Browser-WASM, WASI y filesystem.
