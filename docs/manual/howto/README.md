# HOWTO

Recetas orientadas a tareas. Para semántica exhaustiva usa la referencia del lenguaje; para contratos Python usa `library-reference`.

- Construir y ejecutar un proyecto.
- Componer varias unidades.
- Conceder capacidades y efectos sin confundir host con lenguaje.
- Diagnosticar fallos estructurados.
- Suministrar admisiones de prueba.
- Guardar, reanudar y reproducir checkpoints.
