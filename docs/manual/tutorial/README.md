# Tutorial progresivo de TEVScript 3.1

Esta ruta enseña TEVScript desde valores exactos hasta una aplicación Total-Core compuesta. El tutorial es pedagógico; la autoridad normativa sigue estando en `spec/` y la referencia exhaustiva en `docs/manual/language-reference/`.

Orden recomendado: 01 valores y exactitud; 02 nombres, bindings y expresiones; 03 control y cotas; 04 funciones y tipos; 05 modelos de datos; 06 estado y eventos; 07 capacidades y efectos; 08 módulos y composición; 09 Field/Transformation/Apply; 10 procesos y continuaciones; 11 unidades V4; 12 Total-Core; 13 admisiones de prueba; 14 checkpoints y replay; 15 aplicación completa.

Todos los ejemplos con bloque `tevs` están ligados a una fuente de `examples/docs/v31/tutorial/` y el validador documental rechaza cualquier deriva entre documentación y fuente.
