# V2 — HISTORICAL compatibility

V2 es **HISTORICAL** como versión publicada, pero su lenguaje de unidades continúa como **compatibility** dentro de 3.1. Total-Core compila fuentes hijas V2 y las proyecta a Program IR V4 sin reinterpretarlas.

Tipos, funciones, recursión, efectos, colecciones y capacidades de esas unidades se consultan en su autoridad V2; 3.1 añade la envolvente de composición, no una segunda semántica para esas construcciones.
