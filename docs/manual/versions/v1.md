# V1 — HISTORICAL compatibility

V1 es una superficie **HISTORICAL** preservada por compatibilidad. Incluye frontend, linking/proyecto, lowering y APIs que siguen expuestas como `PUBLIC_COMPATIBILITY`. No es el perfil de fuente actual Total-Core.

Los artefactos/evidencias V1 no se reescriben para aparentar semántica 3.1. Cuando una API V1 continúa pública, su página está separada de la API actual.
