# DEPRECATION y compatibility

Una superficie puede ser histórica/compatibilidad sin estar eliminada. `PUBLIC_COMPATIBILITY` significa que sigue expuesta y debe documentarse/probarse; no debe presentarse como API Total-Core nueva.

**DEPRECATION** requiere una decisión explícita de versión/gobernanza. Este manual no declara obsoleta una API sólo porque exista una alternativa más reciente. Las rutas V0.2/V1/V2/V3 se mantienen separadas para evitar confundir compatibilidad con current.
